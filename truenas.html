TrueNAS Home Server & Private Cloud

Self-hosted Infrastructure Project

Scroll
Project Date 2024 - Present
Role System Administrator
Users ~10 Active Users
Storage 12TB RAIDZ1

Project Overview

Built and deployed a comprehensive TrueNAS-based home server infrastructure providing private cloud services to approximately 10 users. This self-hosted solution demonstrates expertise in Linux system administration, storage management, containerization, and network services.

Infrastructure & Storage

  • TrueNAS OS Deployment: Designed and implemented a TrueNAS Scale server as the primary operating system for managing storage and virtualization workloads.

  • RAIDZ1 Storage Configuration: Configured a RAIDZ1 array with four 4TB drives providing 12TB of usable storage with single-disk parity for fault tolerance. This setup demonstrates understanding of RAID levels, data redundancy, and storage optimization.

  • Power Management: Integrated UPS (Uninterruptible Power Supply) with automated shutdown procedures to protect against data loss during power outages, ensuring data integrity and system reliability.

Services & Applications

Deployed and managed multiple containerized services using Docker and Kubernetes:

  • Tailscale: Secure VPN mesh network for remote access to services from anywhere with zero-trust security model.

  • Immich: Self-hosted photo and video management platform, providing privacy-focused Google Photos alternative.

  • Nextcloud: Comprehensive cloud storage and collaboration platform for file sharing, calendar, contacts, and productivity tools.

  • Navidrome: Modern music server and streamer compatible with Subsonic/Airsonic clients for personal music library management.

  • Home Assistant: Home automation platform for IoT device integration and smart home control.

  • Jellyfin: Open-source media server for streaming movies, TV shows, and media content to multiple devices.

Technical Skills Demonstrated

  • Linux System Administration: Deep understanding of Linux package management, system configuration, user management, and service deployment.

  • Container Orchestration: Hands-on experience with Docker containerization and Kubernetes (K8s) orchestration for managing microservices architecture.

  • Storage Management: Expertise in ZFS filesystem, RAID configurations, data redundancy strategies, and storage optimization techniques.

  • Network Administration: Configuration of network services, VPN setup, reverse proxies, SSL/TLS certificates, and network security best practices.

  • Data Management: Implementation of backup strategies, snapshot management, data migration, and disaster recovery planning.

  • Infrastructure as Code: Automated deployment and configuration management using containerized applications and orchestration tools.

Key Achievements

  • Successfully deployed and maintained a multi-user private cloud infrastructure serving ~10 users with 99.9% uptime.

  • Configured fault-tolerant storage system with RAIDZ1, ensuring data redundancy and protection against drive failures.

  • Implemented automated power management with UPS integration, preventing data corruption during unexpected power outages.

  • Gained comprehensive knowledge of Linux ecosystem, system administration, and cloud infrastructure management.

  • Built practical experience with modern DevOps tools including Docker, Kubernetes, and infrastructure automation.

Technologies Used

OS & Platform: TrueNAS Scale (Linux-based), ZFS Filesystem

Containerization: Docker, Kubernetes (K8s)

Services: Tailscale, Immich, Nextcloud, Navidrome, Home Assistant, Jellyfin

Storage: RAIDZ1 (4x 4TB drives), ZFS snapshots and replication

Hardware: UPS for power management and automated shutdown

Network: VPN, Reverse Proxy, SSL/TLS certificates
